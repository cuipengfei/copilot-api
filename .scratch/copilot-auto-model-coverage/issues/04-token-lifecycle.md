# 04: 令牌到期及凭据变化后保持正确配对

Status: ready-for-human
Blocked by: 02 启动时发现更多模型

**What to build:** 每条模型配对使用其上游 `expires_at` 决定有效期和刷新时间。Copilot 凭据变化时使旧配对失效，重新探测所得的令牌按新选中的模型 ID 登记。

## Acceptance criteria

- [x] 每条配对独立判断有效期，并在到期前五分钟安排刷新；同一模型存在多个有效令牌时保留一条即可。
- [x] 刷新选出不同模型时按新模型 ID 更新映射，不把新令牌写到旧模型名下。
- [x] Copilot 凭据变化立即使旧配对失效；旧凭据下已发起的探测结果不能加入新凭据映射。
- [x] 同一探测点并发刷新时共享在途任务，其他探测点仍可继续工作；请求只使用当前凭据对应的有效配对。
- [ ] 可重复验证有效期边界、凭据变化与并发更新；真实上游请求须先取得授权。

**规格：** [Copilot Auto 模型覆盖与会话迁移](../spec.md)
